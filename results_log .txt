PANEL G  SHARP WORST-CASE BOUNDS UNDER SUPPRESSION
--------------------------------------------------------------------------------
  Suppression is a deterministic threshold rule, so a selection model with an
  exclusion restriction is inapplicable. OLS is linear in y, so the exact
  bounds follow in closed form from the FWL weights -- equivalent to searching
  all 3^275 admissible assignments.
  Bounds require a continuity correction: a suppressed cell may truly hold zero
  female managers, at which the uncorrected statistic diverges.
    c=0.25  sharp set [-2.0073, +0.3496]  width 2.3569   <-- sign NOT identified
    c=0.5   sharp set [-1.8582, -0.0772]  width 1.7810
    c=1.0   sharp set [-1.7574, -0.4814]  width 1.2759
  The sign of the coefficient is not identified once suppressed cells are
  bounded and the correction is small. This is a property of the published
  data, not of the estimator.
  Cells where TOTAL1_2 is also suppressed hold at most 2 managers in total,
  so the mid_tot>=10 filter excludes them by construction, not by convenience.

  Counterfactual release rule: flag true zeros separately from counts of 1-2.
  Publishing the [0,2] bounds would add nothing -- they are already implied by
  the rule. What cannot be recovered is whether a withheld count is 0 or 1-2,
  and the zero case is what makes the lower bound diverge as c -> 0.
    c=0.0   current diverges                zeros flagged [-1.4618, -0.6687]  width 0.7931
    c=0.25  current [-2.0073, +0.3496]      zeros flagged [-1.4696, -0.7822]  width 0.6874
    c=0.5   current [-1.8582, -0.0772]      zeros flagged [-1.4814, -0.8717]  width 0.6097
    c=1.0   current [-1.7574, -0.4814]      zeros flagged [-1.5089, -1.0066]  width 0.5023
  With zeros flagged the sign is identified at every correction, the set narrows
  roughly threefold, and dependence on the correction largely disappears.
